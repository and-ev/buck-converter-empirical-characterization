# Data provenance

`raw/` contains the two CSV files supplied with the completed physical project.
Neither file is modified by the analysis.

- `buck_data.csv` is the original export. Its final header is `temp_C_`.
- `buck_data_new.csv` contains the same 121 measurement rows and corrects only
  that header to `temp_C`. It is the canonical analysis input.

The numeric payloads are identical after normalizing the temperature-column
name. Every file in `processed/` is generated by `analysis/analyze.py` and is
therefore derived, not raw measurement data.

The dataset records elapsed time, converter output voltage, load voltage,
current, load power, shunt voltage, and temperature. No input-current channel
is present, so converter efficiency cannot be calculated from this run.
